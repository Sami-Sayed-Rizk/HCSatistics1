# رفع النسخة على GitHub Pages

1. أنشئ مستودعاً جديداً (Repository) على GitHub، ومثلاً اسمه `syndicate-compare`، واجعله Public.
2. ارفع كل محتويات مجلد `pwa` كما هي (ملف index.html وملف sw.js وملف manifest.webmanifest ومجلد icons) إلى جذر المستودع. لا ترفع المجلد نفسه داخل مجلد آخر.
3. من تبويب Settings ثم Pages، اختر Source = Deploy from a branch، ثم Branch = main والمجلد / (root)، واضغط Save.
4. بعد دقيقة ستظهر الرابط: https://اسمك.github.io/syndicate-compare/
5. على الموبايل افتح الرابط:
   - Android (Chrome): القائمة ثم "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
   - iPhone (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

ملاحظة: الخدمة تحتاج HTTPS، وGitHub Pages يوفره تلقائياً.
